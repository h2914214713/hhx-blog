写给未来的
自己看。

这个博客没有算法推荐，没有流量焦虑。它只是我把踩过的坑写下来的地方。

为什么写。生产环境里学到的东西，有一部分永远进不了官方文档——比如虚拟线程上线后连接池要调小、比如一次 3 秒的 GC 停顿背后是 Humongous 对象。这些经验如果不写下来，半年后连我自己都会忘。

写什么。主线和博客名字一样朴素：Java 后端、AI 工程，以及这两者与前端交界的地方。不写「一分钟入门」，也不写「XX 已死」。每篇都尽量带一次真实的故障、一组真实的数字。

怎么写。先用 Markdown 写清楚问题，再回到代码里验证。所有结论都在本地或测试环境复现过，网上抄来的说法会用「据说」标注。

关于技术栈。这个站是手写的 HTML + CSS + 一点原生 JavaScript，没有框架、没有构建步骤、没有依赖。托管在 Cloudflare Pages，源码在 GitHub。加载整个首页的传输量不到 80KB。

如果你在文章里发现了错误，欢迎直接发邮件告诉我。被指出错误是这件小事里最开心的部分。
